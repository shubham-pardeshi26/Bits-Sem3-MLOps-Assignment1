03Data acquisition and cleaning

  • Raw files verified by pinned SHA-256 checksums; no network needed when they match
  • ? and impossible zeros (cholesterol, blood pressure) → missing; duplicates dropped
  • Different tests per hospital → stratify by site × class, keep missing indicators, never use site as a feature
data.py EDA notebook
Highlight: ca 66% and thal 53% missing overall; Switzerland never recorded cholesterol; prevalence 36–93%.

04Exploratory analysis

  • Diseased patients: older, lower max heart rate, more ST depression
  • Derived feature hr_achieved_frac = thalach / (220 − age)
eda.py all figures
The fraction of age-predicted maximum heart rate reached is a known cardiac risk marker (chronotropic incompetence).

05Feature pipeline: preprocessing inside the model

13 raw inputs→ + hr_achieved_frac→ impute + missing indicators→ scale numerics→ one-hot (NaN = own category)→ model 
Pipeline([
    ("features", FunctionTransformer(add_clinical_features, ...)),
    ("preprocess", ColumnTransformer([
        ("num", make_pipeline(SimpleImputer(strategy="median", add_indicator=True), StandardScaler()), NUMERIC),
        ("bin", SimpleImputer(strategy="most_frequent", add_indicator=True), BINARY),
        ("cat", OneHotEncoder(handle_unknown="ignore", sparse_output=False), CATEGORICAL),
    ])),
    ("model", model),
])
  • Saved as one artifact (models/cardiorisk_model.joblib); API and CLI share one scoring function → no training–serving skew
features.py
Because the imputers and scaler are fitted inside the pipeline, they only ever see training folds: no leakage.

06Model development and selection

  • Baseline, elastic-net logistic regression, random forest, gradient boosting; grid search, 5-fold CV stratified by site × class (85 configurations)
  • Selection on CV ROC-AUC, never on the test set → logistic regression, 0.907 ± 0.029
train.py metrics table
Tree models are within one CV standard deviation; the linear model is simpler to serve and to explain.

07Champion on the hold-out (184 patients)

  • ROC-AUC 0.906 · accuracy 0.842 · precision 0.829 · recall 0.902 (92 of 102 sick patients caught)
10 missed, 19 false alarms; for screening, recall is the metric that matters most.

08Does it transfer to a new hospital?

  • Leave-one-site-out: Cleveland 0.88, Hungary 0.90, but Switzerland 0.75 and VA 0.73 → a new hospital needs local validation
Different prevalence and recording practice cause the drop; an honest limitation and the basis for future work.
